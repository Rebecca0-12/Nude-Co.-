# Nude & Co. — Nail Studio Landing Page

A minimalist, editorial-style single-page website concept designed for a boutique nail studio. Built as a client-style project to capture a calm, luxury aesthetic — from a striking split-screen hero to services, gallery, pricing, testimonials, and a booking form.

**🔗 Live Demo:** [view the website](https://nudeandco.netlify.app)

## About This Project

This was designed as a complete front-end concept for a nail studio business, aiming for a quiet-luxury feel rather than the typical bright, busy beauty-salon website. The design leans on a warm neutral palette, serif/sans-serif type pairing, and plenty of negative space to make the brand feel intentional and premium.

## Features

- **Custom cursor interaction** with a dot + trailing ring effect
- **Split-screen hero section** with staggered fade-in entrance and a floating stat badge
- **Scrolling marquee banner** highlighting core services
- **Services grid** with numbered cards and hover reveal accents
- **Studio story section** with an asymmetric image collage
- **Horizontally scrolling gallery** of nail art work
- **Three-tier pricing section** with a highlighted "Most Popular" plan
- **Customer testimonials** with star ratings and large quote marks
- **Booking form** with service selection and special request field
- **Scroll-reveal animations** using the Intersection Observer API
- Fully responsive across desktop, tablet, and mobile breakpoints

## Tech Stack

- HTML5
- CSS3 (custom properties, CSS Grid, Flexbox, custom cursor)
- Vanilla JavaScript (Intersection Observer, scroll & mouse events)
- Google Fonts — [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) & [DM Sans](https://fonts.google.com/specimen/DM+Sans)

No frameworks, no build tools — a single self-contained HTML file, deployed as a static site.

## Running Locally
